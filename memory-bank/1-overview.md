# 1. Overview del producto

El proyecto es un dashboard financiero con datos simulados.

- Muestra ingresos, gastos, beneficio y margen de beneficio.
- Presenta dos gráficos con datos mensuales.
- La API genera 360 movimientos de los últimos 12 meses completos.
- Los movimientos incluyen fecha, importe, operación, categoría y tipo de negocio.
- La API permite filtrar datos; la interfaz aún no ofrece filtros.
