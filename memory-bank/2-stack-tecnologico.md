# 2. Stack tecnológico

- **Backend:** Python 3.13, FastAPI y Uvicorn.
- **Frontend:** React, TypeScript y Vite.
- **Interfaz:** Tailwind CSS y Recharts.
- **Contenedores:** Docker Compose con recarga durante el desarrollo.
- **Pruebas:** pytest para el backend y Vitest para el frontend.

El frontend usa el puerto 5173. El backend usa el 8000 y expone el 5678 para depuración.
