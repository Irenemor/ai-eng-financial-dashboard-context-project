## 🔄 Mantenimiento

### Actualizar Memory Bank
1. Modifica archivo específico (1-6-*.md)
2. Actualiza memory-bank.md (copia sección)
3. Actualiza INDEX.md si cambia estructura
4. Commitea cambios con commit message descriptivo

### Versioning
- **Formato**: YYYY-MM-DD (fecha última actualización)
- **Ubicación**: Pie de página en cada documento
- **Changelog**: Próxima versión

### Cadencia
- **Mínima**: Cada release (semanal/mensual)
- **Recomendada**: Cada sprint (bi-semanal)
- **Profunda**: Anual (revisión total)
