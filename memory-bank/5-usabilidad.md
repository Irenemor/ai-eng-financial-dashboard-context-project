# 5. Usabilidad

- La interfaz usa un tema oscuro y se adapta a distintos tamaños de pantalla.
- Cuatro tarjetas muestran ingresos, gastos, beneficio y margen.
- El encabezado muestra el primer y último mes de los datos.
- Dos gráficos muestran la evolución mensual.
- Los gráficos se pueden explorar con el teclado y ofrecen tablas de datos.
- Hay indicadores de carga y un mensaje si falla la petición.
- El usuario puede consultar los datos desde un navegador.

El dashboard no ofrece filtros ni actualización automática.
